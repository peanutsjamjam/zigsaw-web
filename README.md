# Zigsaw（Web 版）

好きな画像からジグソーパズルを作って遊べる Web アプリです。
[macOS 版 Zigsaw](https://github.com/peanutsjamjam/Zigsaw) の移植です。

![ゲームプレイ画面](ss_2026-07-25_19.30.13.png)
![セットアップ画面](ss_2026-07-25_19.34.05.png)


## できること

- サーバーのギャラリーにある画像から、好きなピース数でジグソーパズルを作って遊べます。
- ログイン（メールアドレス＋パスワード）すると、途中の状態を保存して中断し、あとで再開できます。
- 画像をアップロードして、みんなで遊べるパズルにできます。
- パズルをクリアすると、そのパズルにコメント（200 文字まで）を 1 件書けます。コメントはパズルごとに一覧表示され、あとから変更もできます。
- 背景色を自由に変更できます。
- 経過時間の表示・非表示を切り替え可能です。

## 開発

技術的な構成・API・開発フローは [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) を参照してください。

サインアップ・ログイン・セッション・パスワード再設定・レート制限は、このリポジトリには実装が無く、
共通ライブラリ [pjj-perl5](https://github.com/peanutsjamjam/pjj-perl5)（`PJJ::*`）を使っています。
`api.cgi` は `PJJ->init(...)` で設定を渡して `auth_dispatch()` を呼ぶだけです。
動かすにはライブラリの clone と、`env.pl` への場所の記載が必要です。
